# Global groundwater-storage-change forecasting: predictive gain attribution

MATLAB code accompanying the study of winner-conditioned hierarchical decomposition of predictive gains from linear model structure, nonlinear model structure, and antecedent hydroclimatic predictors using Global Land Data Assimilation System (GLDAS) products.

## Repository contents

| Directory | Purpose |
|---|---|
| `s1_scripts/s1_data_prepare/` | Extract, aggregate, and harmonize GLDAS-Noah and GLDAS-DA records and build the common 1-degree mask. |
| `s1_scripts/s2_linear_models/` | AR, ARIMA, and SARIMA. |
| `s1_scripts/s3_nonlinear_models/` | SVM, RF, and LSTM. |
| `s1_scripts/s4_nonlinear_x_models/` | SVMX, RFX, and LSTMX with antecedent predictors. |
| `s2_analysis/` | Nine-model evaluation, hierarchical attribution, model selection, normalization sensitivity, and spatial block bootstrap. |
| `s6_SKLGB_sensitivity_2000_fixed_dualPC/` | Fixed 2,000-grid hyperparameter sensitivity; two PCs, 1,000 cells per PC. Includes compact completed-PC outputs for independent re-aggregation. |
| `s7_SKLGB_extend_2019_2021_singlePC/` | Extended 2019–2021 test-year experiment on 2,000 cells; one PC. |
| `s8_SKLGB_monthlymean_target_2000_singlePC/` | Monthly-mean versus month-end groundwater-storage-change target sensitivity on 2,000 cells; one PC. |
| `s9_Koppen_Climate_Analysis_Package/` | Five-zone Koppen-Geiger climate analysis; no model retraining. Includes the 1-degree categorical climate GeoTIFF. |

Each of the four additional experiment directories has an English `README.md` with its precise workflow. See also [RUNNING.md](RUNNING.md) and [SOURCE_INVENTORY.md](SOURCE_INVENTORY.md).

## Inputs and software

Original input products: GLDAS-Noah Version 2.1 and GLDAS Data Assimilation Version 2.2. Raw GLDAS files, the complete preprocessed 17,284-cell master database, and most full-domain forecasts are **not bundled**. The small MAT files in the sensitivity folders are deliberate exceptions: they preserve the fixed sample, baseline reference, and/or compact two-computer outputs required for independent re-analysis. The climate analysis still requires `s3_uc_analysis1_results.mat`, generated by the main analysis pipeline, which is not included.

MATLAB is required, with toolboxes appropriate to the script: Statistics and Machine Learning, Deep Learning, Econometrics, System Identification, and Parallel Computing when enabled. Some scripts also use MATLAB geographic raster/table functions. Software versions and external data availability may affect reproduction.

**Important:** The scripts largely retain the original Windows absolute `projectRoot`/data paths. Set these paths to your local directories before execution. See `RUNNING.md`. No nine-model training or scientific analysis was run while preparing this repository package.

## Interpretation

The forecast target is GLDAS-represented monthly groundwater-storage change at 1-degree resolution, not direct well observations. Model winners and the monthly oracle are retrospectively selected with observed test-period errors. The decomposition is diagnostic and conditional on the model hierarchy; it is not a causal attribution or a deployable prospective selector.

## Citation and reuse

Please cite the accompanying manuscript when using the code. The climate raster derives from the Koppen-Geiger dataset described by Beck et al. (2023), *Scientific Data*, 10, 724, DOI: `10.1038/s41597-023-02549-6`. No software license has yet been selected for this repository.
